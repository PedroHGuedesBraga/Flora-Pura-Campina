# Catálogo Flora Pura

Site estático em Next.js (perfumes e body splashes).

- `npm install && npm run dev` (http://localhost:3002)
- `npm run build` gera a pasta `out` (deploy: Cloudflare Pages, build `npm run build`, saída `out`)
- Dados: `data/catalogo.json`, gerado por `scripts/gerar_catalogo.py`
